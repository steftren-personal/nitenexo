## Befunde (gemessen auf iPhone 14, DPR 3)
1. **Seitliches Scrollen**: `body { overflow-x: hidden }` reicht auf iOS Safari nicht. Elemente, die über den Rand ragen: `.thread-env-img` (531 px breit bei 489 px Viewport, left -21), `.bw-marquee-track` (width: max-content, 3162 px) im Kanäle-Marquee, `.bw-mq-group`, `.bw-logo-item`. Fix: `html, body { overflow-x: clip }` (Safari 16+; Fallback hidden), Marquee-Wrapper `.bw-marquee { overflow: clip; contain: paint }`, `.thread-env-img` auf 100 % Breite ohne negativen Offset im Mobile-Gate; danach mit Playwright (iPhone 14, `document.documentElement.scrollWidth <= innerWidth`) über die GESAMTE Seitenhöhe prüfen (an 10 Scroll-Positionen, denn Elemente werden erst beim Reveal breit).
2. **Qualität**: Der Mobil-Scrub nutzt `film-mobile.mp4` (540x960) auf einem 3x-Display = matschig, dazu Kompressions-Artefakte beim Scrubbing. **Auf dem Handy KEIN Video mehr.** Stattdessen pro Szene ein scharfes Standbild (liegt in `assets/film/mobile/<szene>.webp` 1080x1920 + `-540.webp`; nach `public/assets/film/mobile/` kopieren) mit **Crossfade beim Scroll**: die 6 Szenen-Stills liegen fixed übereinander (`position: fixed; inset: 0; object-fit: cover`), Opacity wird per ScrollTrigger je Kapitel geblendet (gleiche Zeit-Map aus `lib/film-timeline.ts` / `scene-map.json`: Szene 1 im Hero, dann je Kapitel eine Szene). Dezenter Ken-Burns (scale 1.0 → 1.06 über die Kapitel-Länge, nur transform) damit es lebt. Bei Reduced-Motion: nur Szene 1 statisch. `srcset` 540/1080 mit `sizes="100vw"`. Preload nur Szene 1 (LCP), Rest `loading="lazy"` aber vor Sichtbarkeit geladen (IntersectionObserver rootMargin 100 %).
3. **Grüne Linie oben** = `.bw-progress` (Scroll-Fortschrittsbalken aus `components/motion/MotionRoot.tsx`): im Mobile-Gate ausblenden (`display: none`), Desktop behalten.
4. **Zwischentext** = die Hero-Caption-Bänder `.tf-band` („Jedes Licht ist eine Anfrage." / „Die KI übernimmt." usw.): auf Mobil komplett ausblenden, der Hero zeigt am Handy direkt die Wortmarke + „Websites, die verkaufen. KI, die mitarbeitet." + Subline + Buttons über Szene 1. Hero-Region am Handy: 100svh statt 800vh-Scrub (kein leeres Scrollen). Auch `.story-thread` (grüne Faden-Linie zwischen Kapiteln) und `.thread-pulse` am Handy ausblenden.
5. Cookie-Banner am Handy: max. 2 Zeilen + 2 Buttons, nicht höher als 120 px, kein Überlappen des Hero-CTA.
